# Solara Energy website

A responsive React/Vite solar installation marketing site inspired by the attached editorial solar reference.

## Run
`npm install && npm run dev`

## Notes
- The site uses configurable placeholder business information (Solara, Lagos, phone/email) because no company details were supplied.
- Contact form validates required fields and presents an honest in-page confirmation. Connect the `submit` handler in `src/main.jsx` to a real backend/email service before production.
- Image URLs are from Unsplash and should be replaced with approved business photography before launch.
